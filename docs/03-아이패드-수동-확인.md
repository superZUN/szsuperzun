# 아이패드 Safari 수동 확인 절차

자동 테스트는 Chromium으로 아이패드를 흉내 낼 뿐입니다. 아래 항목은 **실제 아이패드에서 한 번** 확인해 주세요. 30분 확인을 빼면 15분쯤 걸립니다.

준비: 아이패드를 충전기에 연결하고 Safari로 배포된 주소를 엽니다.

## A. 처음 열었을 때 (2분)
- [ ] 설정·API 키·용어 사전이 예전 그대로 보인다 (설정 탭).
- [ ] 회의록 탭에 예전 회의록이 보이고, 개수가 예전과 같다.
- [ ] 할 일 탭에 예전 할 일이 보인다.
- [ ] 화면 아무 곳이나 두 손가락으로 벌리거나 두 번 탭해도 **확대되지 않는다**.
- [ ] 입력칸(메모·질문)을 눌러도 화면이 확대되지 않는다.

## B. 시작과 게이지 (3분)
- [ ] '시작'을 누르면 마이크 허용을 묻는다 → 허용.
- [ ] 받아쓰기 줄 위에 `MIC [막대] · 인식 ● 듣는 중 · 마이크 점검`이 보인다.
- [ ] 말하면 MIC가 **말소리**, 인식이 **알아듣는 중**으로 바뀌고 글자가 나온다.
- [ ] 조용히 있으면 MIC가 **조용함**이다. (선풍기·키보드 소리에 '말소리'가 뜨면 알려 주세요.)
- [ ] 마이크 허용 배너가 자꾸 뜨면 Safari 'ᴀA' → 웹사이트 설정 → 마이크 → **허용**으로 바꾼다. 안내 문구도 나와야 한다.

## C. 마이크 점검 (1분)
- [ ] '마이크 점검'을 누르고 안내대로 ① 5초, ② 6초 말한다.
- [ ] 결과가 나온다. "둘이 부딪힘"이 나오면 **게이지 끄고 인식만 쓰기**를 누른다. (이 결과는 개발자에게도 알려 주세요.)
- [ ] 닫으면 다시 듣기 상태로 돌아온다.

## D. 30분 연속 사용 (가장 중요)
1. 설정 → Audio → **하루 종일 켜두기는 끈 상태**로 시작한다.
2. 실제 회의나 유튜브 강의를 틀어 두고 30분 둔다. 화면은 켜 둔 채 다른 앱으로 가지 않는다.
- [ ] 30분 동안 화면이 꺼지지 않았다.
- [ ] 30분 동안 인식 상태가 **꺼짐**이나 **소리는 들리는데 글자가 안 나옴**에 오래 머문 적이 없다.
- [ ] '다시 켬 N회' 숫자를 적어 주세요: ____회. 예전 앱은 Safari에서 45초마다 다시 켰지만, 새 앱은 브라우저가 끝낼 때만 다시 켭니다. 그래서 숫자가 훨씬 작아야 합니다.
- [ ] 마이크 허용 배너가 몇 번 떴는지 적어 주세요: ____번.
- [ ] 끝나고 회의록 작성을 눌러 회의록이 만들어지는지(준비중 → 확정) 확인한다.

## E. 하루 종일 켜두기 (5분)
- [ ] 설정에서 켜고 3분간 조용히 두면 검은 화면에 시계가 나온다 (SLEEP).
- [ ] 말을 걸면 다시 깨어난다. 화면을 탭해도 깨어난다.

## F. 손동작 (2분)
- [ ] 카드 한 번 탭 = 크게 보기, 두 번 탭 = 고정(테두리), 다시 두 번 탭 = 해제.
- [ ] 카드를 끌었다 놓으면 제자리로 돌아온다. 휙 던지면 날아가고 다른 카드가 들어온다.
- [ ] '기록' 보드에서 두 손가락으로 확대·축소가 되고, 판을 끌어 둘러볼 수 있다.
- [ ] 할 일을 옆으로 밀면 지워지고, '되돌리기'가 5초 동안 나온다.

문제가 있으면 항목 번호와 화면 캡처를 보내 주세요.
