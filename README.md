# 회의 옆자리 (Meeting Sidekick)

아이패드 Safari에서 하루 종일 켜 두고 쓰는 한국어 실시간 회의·대화 보조 웹 앱. 재구축 진행 중 — 계획은 `docs/01-legacy-분석보고서.md`.

- `npm run dev` — 개발 서버
- `npm run build` — `dist/` 생성 (Netlify가 배포)
- `npm test` — Playwright 테스트 (`tests/e2e`, 하네스는 `tests/harness`)
- `legacy/` — 예전 단일 HTML 앱 (참고용, 배포되지 않음)

배포·환경변수 안내는 마지막 단계에서 채웁니다.
